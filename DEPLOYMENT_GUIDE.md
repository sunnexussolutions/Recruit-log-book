# 🚀 Recruit Logbook — Complete GitHub Push & Vercel Deployment Guide

This guide walks you through pushing the **Recruit Logbook** application codebase to **GitHub** and deploying it live on **Vercel** with the **Neon Serverless Postgres** backend.

---

## 📋 Prerequisites & Architecture Overview

- **Frontend**: Responsive Web UI (`login.html`, `admin-dashboard.html`, `member-dashboard.html`)
- **Backend API**: Express.js server (`server.js`) configured with Vercel Serverless Functions (`vercel.json`)
- **Database**: Neon Serverless Postgres (`@neondatabase/serverless`)
- **Mobile Apps**: Capacitor Android & iOS native containers (`www/`)

## 🐙 Part 1: Push Code to GitHub


### Step 2: Create a Repository on GitHub
1. Open your browser and navigate to [github.com/new](https://github.com/new).
2. Set the **Repository name**: `recruit-logbook`.
3. Set visibility to **Public** or **Private**.
4. Leave **"Initialize this repository with..."** options unchecked (do NOT add README or .gitignore from GitHub, as we already have them).
5. Click **Create repository**.

### Step 3: Link Local Repo & Push
In your project terminal, execute the following commands (replace `YOUR_GITHUB_USERNAME` with your actual GitHub username):

```bash
# Add your GitHub repository as remote origin
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/recruit-logbook.git

# Push your code to GitHub
git push -u origin main
```

## ⚡ Part 2: Deploy Backend & Web App to Vercel

Vercel hosts the web app and turns `server.js` into serverless API functions automatically using the included `vercel.json`.

### Method A: Deploy via Vercel Dashboard (Recommended)

1. **Log in to Vercel**:
   Go to [vercel.com](https://vercel.com) and log in (or sign up using your GitHub account).

2. **Import GitHub Project**:
   - Click **"Add New..."** ➔ **"Project"**.
   - Select your GitHub account and find the **`recruit-logbook`** repository.
   - Click **Import**.

3. **Configure Project Settings**:
   - **Framework Preset**: Select `Other` (or leave default).
   - **Root Directory**: `./` (leave default).

4. **Add Environment Variables**:
   Under **Environment Variables**, add the following required key:

   | Key | Value | Description |
   | :--- | :--- | :--- |
   | `DATABASE_URL` | `postgresql://neondb_owner:YOUR_PASSWORD@ep-xyz.us-east-2.aws.neon.tech/neondb?sslmode=require` | Your Neon Postgres connection string from `.env` |
   | `PORT` | `3000` | Optional fallback port |

5. **Deploy**:
   Click **Deploy**. Vercel will build and deploy your application in under 60 seconds!
   You will receive a live URL (e.g., `https://recruit-logbook.vercel.app`).

---

### Method B: Deploy via Vercel CLI (Alternative)

If you prefer using the command line:

```bash
# 1. Install Vercel CLI globally
npm install -g vercel

# 2. Deploy project
vercel

# 3. Add the production DATABASE_URL variable
vercel env add DATABASE_URL

# 4. Deploy to Production
vercel --prod
```

## 🐘 Part 3: Neon Database Verification

Ensure your Neon Postgres tables are created and seeded:

1. **Database Schema**:
   The full schema SQL is located in `db/schema.sql`.

2. **Initialize Database Tables & Default Users**:
   Run the setup script locally (or against your production Neon DB):
   ```bash
   npm run db:init
   ```

   This creates the following tables:
   - `users` (Admin & Member credentials)
   - `attendance_logs` (Check-in / Check-out telemetry)
   - `daily_work_reports` (Daily task protocols)
   - `weekly_reports` (Progress & skills updates)
